# Companion v1 canonical vectors

`python3 generate.py` is an independent Python encoder. Complete command bytes are in `*.hex` and checked by Rust, not generated by the Rust encoder. Fixed IDs end in 1 (note), 2 (author), 3 (operation), 4 (item), 5 (reference).

New command tags: `8` Companion, `9` SetCompanionSettings. Existing SYNO v1 prefix, command envelope, dependency sorting, tags and payloads are untouched.

Companion = tag 8, u32 mutation count, then for each: ID string, existing base encoding, tombstone u8 (0/1), body JSON string. Settings = tag 9, base, settings JSON string. JSON strings use a u32 byte count and UTF-8, compact serde externally-tagged enum layout, declared field order, unchanged variant/field names, shortest serde_json number representation (including `.0` for integral f64), no optional/unknown fields, no ASCII escaping of Unicode. This typed JSON spelling is frozen canonical data, not arbitrary incoming JSON or JSON equality. Limits validate before commit; valid bodies contain no nonfinite numbers. Future changes require a new tag, not changing these layouts.

Body and settings fields are specified by `companion_types.rs`; all enum and field names/order in that file are frozen for tags 8/9. A drawing is at most 12 steps, 400 primitives and 64 KiB of body bytes. The vectors cover a range anchor, pinned margin note, thread message, drawing primitives and note settings.
