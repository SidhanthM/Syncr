## What and Why

This project is my continuous stab at making my own notes app to do exactly what I need. I love Samsung Notes, especially how smooth it was for baseline writing. However, doing all this on a tiny screen, even an Ultra isn't ideal + proprietary + can't view elsewhere (couldn't even log in on Web to sync with Cloud), so I wanted to make my own, and this was the end result.

I also got much more comfortable with Obsidian, and wanted to integrate the modular bits that I loved there, here. 

So now I'm aiming for it to be an All-in-one that can handle native drawing as though it were a drawing tablet with super smooth drawing .

It is built around the S Pen on the Galaxy S23 Ultra, but it uses only Android's standard stylus APIs, so it is meant to work on any Android phone with an active stylus.
